# Adworthy.ai

Make killer ads in seconds. Recreate viral ad styles from Pinterest, Facebook, and more.

## Tech Stack

- React + TypeScript + Vite
- Tailwind CSS + shadcn/ui
- Supabase (auth + database)
- Stripe (billing)
- Cloudflare (hosting)

## Getting Started

```bash
npm install
npm run dev
```
